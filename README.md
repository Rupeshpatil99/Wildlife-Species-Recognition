# 🐾 Wildlife Species Recognition

A deep learning and computer vision project for automatically identifying wildlife species from images using **TensorFlow, Keras, and MobileNetV2 Transfer Learning**.

The system analyzes wildlife images and classifies them into **47 different animal species**. The project includes dataset analysis, preprocessing, image augmentation, transfer learning, model training, fine-tuning, and comprehensive model evaluation.

---

## 📌 Project Overview

Wildlife monitoring and species identification are important for biodiversity research and conservation. Manually identifying animals from large collections of images can be time-consuming.

This project develops an automated image classification system that can recognize wildlife species from photographs.

The system uses **MobileNetV2**, a pretrained convolutional neural network, as a feature extractor and adds a custom classification layer for identifying 47 wildlife species.

---

## 🎯 Objectives

- Analyze and understand the wildlife image dataset.
- Identify and organize 47 different wildlife species.
- Check the dataset for corrupted images.
- Analyze class distribution and image dimensions.
- Split the dataset into training, validation, and testing sets.
- Resize images to a consistent input size.
- Normalize image pixel values.
